Exercício Criado para aula de técnico em informática para internet turma 15

-> criar pasta localmemnte
-> Nomear a pasta como exercicio-node-nome
-> Criar package.json (terminal -> npm init)
-> Adicionar Descrição e Autor (GUS)
-> Definir pasta principal como app.js
-> Criar package-lock.json (termonal -> npm install)
-> Criar arquivo app.js e abrir a porta 3000 para host local
-> Realizar commits de cada etapa separadamente 
-> Criar README com passo a passo do processo
-> Sincronizar a criação do README no VSC
